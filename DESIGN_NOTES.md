# Design Notes

## Rejeitado
- Dashboard escuro excessivamente denso.
- Tipografia condensada em quase todos os títulos.
- Verde-limão dominante e aparência próxima de produto gamer/apostas.
- Muitas caixas equivalentes, sem uma tese visual clara.

## Próxima direção
- Plataforma esportiva institucional internacional.
- Base clara mineral, verde profundo e amarelo-sinal usado com disciplina.
- Hero de placar como assinatura; restante mais editorial e legível.
- Archivo para display, Manrope para UI e Roboto Mono para dados.
